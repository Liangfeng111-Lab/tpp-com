# tpp.com

A deal & savings website similar to Hip2Save — built with vanilla HTML, CSS, and JavaScript.

## Features

- 🏷️ Daily deals from Amazon, Walmart, Target, Best Buy & more
- 🎫 Coupon codes with one-click copy
- 🍽️ Budget-friendly recipes
- 🔨 DIY projects & crafts
- 💡 Money-saving tips & life hacks
- 📤 Community deal submissions
- 🏪 Browse by store & category
- 🔍 Search & filter
- 📱 Fully responsive
- 🌙 Fast, static, no dependencies

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (ES5 compatible)
- Zero frameworks, zero build steps

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → "New Project"
3. Import your GitHub repo
4. Vercel auto-detects static site — no config needed
5. Click "Deploy"

Done! Your site is live.

## Local Development

Just open `index.html` in any browser. No server needed.
